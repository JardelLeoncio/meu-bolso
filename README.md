# Meu Bolso

Aplicativo web simples para registrar despesas, acompanhar gráficos mensais e gerar backups locais.

## Executar localmente

Abra a pasta no VS Code e use a extensão **Live Server**, ou abra `index.html` no navegador.

## Privacidade

O aplicativo guarda os lançamentos no armazenamento local do navegador. Backups e dados financeiros pessoais não fazem parte deste repositório: eles estão protegidos pelo `.gitignore`.

Antes de limpar dados do navegador ou trocar de aparelho, gere um backup em **Configurações → Baixar backup (.json)** e guarde-o em um local privado.

## Publicação

O projeto é estático e pode ser publicado pelo GitHub Pages. Envie apenas os arquivos versionados pelo Git; nunca envie arquivos de backup ou históricos pessoais.
