# Meu Bolso

Aplicativo pessoal de controle financeiro para acompanhar saldos, entradas, gastos e contas a pagar em um só lugar.

- **Início** — saldos, histórico de despesas, gráficos e próximos vencimentos.
- **Cartões** — movimentações bancárias, faturas e limites.
- **Despesas** — lançamentos manuais, vencimentos e pagamentos.
- **Ajustes** — aparência, notificações, backups e segurança da conta.

Funciona no computador e no celular, com temas claro e escuro e instalação na tela inicial. Os dados ficam na conta autenticada, com sincronização entre aparelhos.

Desenvolvido com JavaScript, Supabase e Pluggy. Hospedado no GitHub Pages. Saldos, cofrinhos e movimentações dependem das informações disponibilizadas pelos bancos.
