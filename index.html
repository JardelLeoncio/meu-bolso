Exportar para Excel

Baixe todos os lançamentos em CSV, organizado por mês, tipo, categoria, valor e situação de pagamento.

Importação rápida de despesas

Cole uma despesa por linha para o mês selecionado, no formato Nome; Valor; Tipo; Pago. Ex.: Aluguel; 850,00; Fixa; Não. As novas despesas serão somadas às existentes.

Começar outro mês

Você pode copiar automaticamente suas contas fixas de um mês anterior, sem copiar as despesas variáveis.

Redefinir aplicativo

Apaga os dados salvos nesta versão do navegador e restaura setembro, outubro e novembro de 2026. Faça um backup antes.

Privacidade: esta versão não tem login, banco de dados online ou sincronização entre aparelhos. Os valores não são enviados para servidores. Para usar como aplicativo na tela inicial, publique os arquivos do projeto em um site HTTPS e use “Adicionar à Tela de Início” no navegador.
